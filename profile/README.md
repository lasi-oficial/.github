## 👥 Como contribuir

Somos uma liga acadêmica e recebemos contribuições de membros ativos.
Se você faz parte da LASI e quer contribuir:

1. Confira as issues abertas nos repositórios
2. Siga o guia de contribuição de cada projeto (`CONTRIBUTING.md`)
3. Abra um Pull Request seguindo as regras de branch protection
